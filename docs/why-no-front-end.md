# Why no front end

A consultant can maintain an evaluation from the same conversation that reviews its evidence. The database records criteria, outcomes, gaps, effort and decisions. Read-only HTML briefs and weekly views show those records without an application to maintain.

A screen gives guided forms, shared navigation, visual scheduling, mobile capture and permission-aware buyer access. This base does not supply those experiences, offline synchronisation or a product demonstration environment. It suits a trusted operator working through a coding agent. Enterprise DNA can build the interfaces and connections the business needs around the same records.
